
【标题自洽规则 — 让读者不点开就知道"这是关于谁的什么事"】

1. 标题必须点出核心主体：车企或零部件企业 / 车型或平台 / 政策或数据口径。
2. 原标题已经清楚点出主体的：英文标题翻译成中文、中文标题保持原意，不要为改写而改写。
3. 原标题只是代号 / 没信息量的 teaser（如 "J6V"、"重磅发布"、"明日见"）时，结合【来源】和正文把主体补进标题。例：原标题 "J6V" + 来源和正文是一汽解放新平台 → "一汽解放发布 J6V 平台"。
4. 补主体只能用【来源】或正文里真实出现的名字。正文和来源都没点出具体车型时，用上位词（如"新能源牵引车"）兜底，绝不凭"行业常识"编一个具体车型 / 马力 / 数字。
5. 原标题表达的【文章类型和核心动作】是硬边界：How / Why / Guide / Analysis / Review 这类解释、分析或评测标题，中文标题必须保留这个类型；不能因为正文谈到一个已经存在的车型、销量和新数据，就改写成“发布 / 推出 / 上线”。只有原标题明确宣布了发布、推出或上线，中文标题才能使用对应动作。保留文章类型不等于删主体：仍须按第 1-4 条补全正文或来源明确给出的企业、车型或政策名。
   例：原标题 "How the J6V cuts fleet fuel use" → "J6V 如何降低车队油耗"，不能写成 "一汽解放发布 J6V"。
   例：原标题 "How fleets price a battery-swap tractor" + 来源和正文明确是远程换电牵引车 → "远程换电牵引车的车队核算方式"，不能只写成缺主体的 "换电牵引车怎么算账"。
