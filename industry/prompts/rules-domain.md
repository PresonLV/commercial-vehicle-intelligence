
【商用车领域用词 — 本平台写的是商用车产业链，严格遵守】

1. 歧义默认值：以下词在卡车、客车语境里按商用车含义写，不要译成乘用车或日常词：
   - commercial vehicle / CV = 商用车（不是“商务车”）
   - heavy-duty truck / HDT / Class 8 = 重卡
   - medium-duty = 中卡
   - light truck / light commercial = 轻卡
   - tractor / tractor unit = 牵引车（货运牵引车；只有农业语境才写拖拉机）
   - rigid / straight truck = 载货车
   - dump / tipper = 自卸车
   - pay-per-kilometre / pay-per-mile / tires-as-a-service = 按公里付费（轮胎即服务）
   - retread = 翻新胎
   - uptime contract / full-service lease = 出勤率合同 / 全包租赁
   - tractor-trailer 里的 trailer = 挂车（不是“预告片”）
   - coach = 公路客车；city bus = 城市公交；school bus 保留“校车”
   - pickup = 皮卡
   - fleet = 车队（物流或客运车队，不是“舰队”）
   - OEM = 整车厂；OES = 原厂服务件；IAM = 独立售后
   - aftermarket = 后市场
   - TCO = 全生命周期成本
   - GVW / GCW = 总质量 / 列车总质量，保留数字和单位
   - China VI / Euro VI = 国六 / 欧六，不要写成“中国六”或“欧洲六”
   - battery swap = 换电；charging = 充电；hydrogen refueling = 加氢
   - LNG / CNG / BEV / PHEV / FCEV / HEV 保留英文缩写，首次可在中文里点明燃气、纯电、插电、氢燃料或混合动力

2. 以下专有名词用行业里通用的中文，英文品牌按原文保留，不要自造译名：
   - 整车：一汽解放、东风商用车、中国重汽、陕汽 / 德龙、福田 / 欧曼、上汽红岩、北奔、徐工、三一、江淮、远程、宇通、金龙、中通客车
   - 动力与部件：潍柴、玉柴、康明斯、宁德时代、法士特、汉德、弗列加这类滤清和后处理品牌，原文怎么写就怎么写
   - 海外品牌车型代号（Auman、SITRAK、HOWO、Jiefang J6、Delong）保留原文或行业通称，不要意译马力、平台代号
   - 机构：中汽协、工信部、交通运输部。CAAM 可写“中汽协”

3. 数字一字不改：
   - 销量、份额、出口量、订单台数、价格、降价幅度、马力、排量、电量 kWh、续航、换电站数量、运价
   - 金额和百分比保留原文的阿拉伯数字和单位，不要改写成“数万台”“大幅增长”
   - 车型名、公告号、标准号、国别市场名称保持原样

4. 不要把乘用车术语套进来：不要把牵引车写成“轿跑”，不要把挂车写成“拖车电影”，不要把车队司机写成“用户体验”。
